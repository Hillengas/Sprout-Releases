# Sprout Downloads

Hier liegen die fertigen Windows-Installer von **Sprout**, einem SVN-Client im Stil von SourceTree für Menschen, die Git kennen.
Sprout zeigt jede SVN-Aktion zusammen mit dem passenden Git-Befehl und bringt Dinge mit, die SVN von Haus aus nicht kann (Staging, Stash, Umbenennungs-Erkennung).

**Neueste Version:** <https://github.com/Hillengas/Sprout-Releases/releases/latest>

| Datei | Für wen |
|---|---|
| [`Sprout-Setup-win-x64.exe`](https://github.com/Hillengas/Sprout-Releases/releases/latest/download/Sprout-Setup-win-x64.exe) | normale 64-Bit-PCs (Intel/AMD) |
| [`Sprout-Setup-win-arm64.exe`](https://github.com/Hillengas/Sprout-Releases/releases/latest/download/Sprout-Setup-win-arm64.exe) | ARM64-PCs (Snapdragon X, Surface Pro X) |

Beide Dateien sind Installer mit Startmenü-Eintrag und Deinstallation. SVN ist enthalten, es muss nichts zusätzlich installiert werden.
Sprout prüft in den Einstellungen unter „Updates“ selbst, ob hier eine neuere Version liegt. Die Datei `Sprout-Release.sig` gehört zu dieser Prüfung und muss nicht heruntergeladen werden.

Der Quellcode wird in einem privaten Repository entwickelt. Dieses Repository dient nur der Verteilung.
